# P0-022 DevTicketManager互換PoC

## 目的

提供された実データを変更せず、DevTicketManagerの最低限の用途を読み込める互換範囲を確定する。

## 前提・依存関係

- P0-005完了
- P0-007完了
- ユーザーから匿名化済みDevTicketManager実データを受領済みであること

## 対象範囲

- Markdown一覧と本文
- 作成・更新日時
- 名前・日時による並べ替え
- 検索
- 確認状態
- 添付関係
- プロジェクト切替に必要な既存構成

## 対象外

- 元ファイルの移動、改名、Front Matter追加
- 自動一括移行
- 実データの恒久保存・再配布
- DevTicketManager全機能の再現

## 対象ファイルまたは対象モジュール

- ユーザー提供の隔離済み実データコピー
- `poc/devticketmanager-compat`
- 互換マッピング表

## 具体的な実装内容

1. サンプルの構成、命名、文字コード、確認状態、添付規則を棚卸しする。
2. 読取専用で一覧と本文を抽出する。
3. 確認状態を`.adm-meta`へ写像する案を検証する。
4. 対応、条件付き対応、非対応を分類する。
5. 原本ハッシュを前後比較する。

## テスト内容

- 通常、確認済み、添付付き、破損・例外サンプル
- 日時と並べ替え結果
- 元ファイル／元フォルダー情報
- PoC前後の原本ハッシュ一致
- 非対応ファイルが全体停止を起こさないこと

## 受け入れ条件

- 最低限機能ごとの互換可否が実データ根拠付きで示される。
- 原本を変更しない。
- 非対応事項と移行時のユーザー確認事項が明記される。
- 移行設計を推測で確定しない。

## ユーザーが目視確認する内容

- 既存一覧とPoC読取結果の比較。
- 確認状態と添付関係の対応表。
- 非対応・要確認一覧。

## 想定されるリスク

- サンプルが運用全体を代表しない。
- ファイル作成日時のコピーで意味が変わる。
- 実データに秘密情報が残る。

## 完了後に更新すべき設計資料

- DevTicketManager移行・互換仕様
- Markdown判別仕様
- `.adm-meta`仕様
- 移行ADR

## 実施結果（2026-08-02）

### 実施内容

- `poc/devticketmanager-compat`に.NET 10の読み取り専用検証ハーネスを作成した。
- Markdownの再帰的棚卸し、本文・見出し抽出、UTF-8 BOM／UTF-8／Windows code page 932（Shift_JIS表記）の判定候補、添付候補、検索・ソート、確認状態の`.adm-meta`写像候補を実装した。
- 入力ツリーの前後SHA-256比較を行い、入力へ書き込まない境界を検証した。
- 入力未指定時は自己検証のみを行い、実データ判定をBLOCKEDとして記録した。

### 結果

- 自己検証: 3ファイル発見、前後ハッシュ一致、PASS。
- 実データ互換判定: BLOCKED（匿名化済みDevTicketManager実データ未提供）。
- 実行結果JSON: `%TEMP%\AI-Development-Manager\poc\P0-022\20260802-125957-c8f70196\result.json`
- SDK: .NET 10.0.302、Runtime: .NET 10.0.10。

### 再実施手順

匿名化済み隔離コピーを受領後、次を実行する。

```powershell
dotnet .\poc\devticketmanager-compat\src\DevTicketManager.Compat.Poc\bin\Release\net10.0\DevTicketManager.Compat.Poc.dll --input D:\path\to\anonymized-devticketmanager-copy
```

### 判定

ハーネス実装と自己検証は完了したが、受入条件に必要な実データ根拠がないため、P0-022はBLOCKEDとする。P0-023以降には着手していない。
