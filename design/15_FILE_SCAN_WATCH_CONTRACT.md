# ファイル走査・監視・再同期契約

版: 0.1-p0-013
状態: PoC完了・採用候補
基準日: 2026-08-02

## 走査契約

- 初回全走査、定期再走査、手動再走査を正とする。
- 対象はMarkdownと`.adm-meta`配下のJSONとする。
- スナップショットは相対パス、サイズ、最終更新時刻、SHA-256を持つ。
- 差分は追加、変更、改名、削除として表現する。
- FileSystemWatcherイベントはパス単位のデバウンスキューへ集約し、監視漏れは再走査で補正する。
- 読込中ファイルは上限付き再試行し、失敗は文書単位エラーとして記録する。
- キャンセル、再開、進捗をサポートし、1文書のエラーで全走査を停止しない。

## PoC結果

`poc/file-scan-watch`で初回3項目、イベントデバウンス、改名・削除・追加、監視漏れ再同期、ロック中ファイル、キャンセル・再開を検証した。.NET SDK 10.0.302、Runtime 10.0.10を使用した。
