# P0-021 UI回帰基準

## レイアウト

- [ ] 1440px標準幅で左ナビ248px、上部バー71px、本文左右43pxが維持される。
- [ ] 820px幅で左ナビ64px、一覧・詳細1列、主要操作表示を維持する。
- [ ] 320px以上で保存、取消、戻る、競合確認が画面外へ消えない。
- [ ] 一画面一責務、見出し→主要内容→次の操作の順序を維持する。

## 操作・状態

- [ ] Tabでナビ、検索、一覧、編集、保存へ到達できる。
- [ ] Enterで選択・実行、Escapeでダイアログを閉じ、Ctrl+Sで保存できる。
- [ ] 保存済み、未保存、競合、接続エラー、容量警告、復元検証中に文言と次の操作がある。
- [ ] 競合時に最新版、自分の変更、差分、次の操作を表示する。
- [ ] アップロード・復元は進捗と取消を表示する。

## 表示環境

- [ ] ライト／ダークでコントラストと状態の意味を維持する。
- [ ] 100%、125%、150%、200% DPIで情報欠落と操作不能がない。
- [ ] Edge、Chrome、WebView2で主要操作の意味が一致する。
- [ ] 日本語IME入力、フォーカスリング、スクリーンリーダー向けラベルを確認する。

## 承認前の保留

- [ ] ユーザー提供の基準画像と主要レイアウト・余白・色・整列を比較する。
- [ ] ユーザーが標準幅・狭幅・状態別代表画面を承認する。

## P1-014 自動検査

- `npm run test`でVitestをjsdom環境で実行し、coverageを`src/Adm.Web/coverage`へ保存する。
- role／label、Tab／Enter／Escape、loading／error、ARIA、API fetch境界をDOM単体テストで検査する。
- fake timerを含む非同期テストは、実時間待ちに依存せず再現可能にする。
- 本項目はDOM単体テストの基盤であり、実ブラウザ、Playwright、WebView2の確認を代替しない。

## P1-015 文言検査

- `npm run messages:check`で表示文言の辞書参照、未知キー、未使用キーを検査する。
- JSXへ日本語の利用者向け文言を直接記述せず、`src/messages/catalog.ts`のキーを利用する。
- 内部値やAPI名を表示せず、「何が起きたか」「次の操作」を一般語で表現する。
- 英語UI、実行時の言語切替、業務画面固有の全メッセージは対象外とする。

## P1-017 アプリシェル検査

- 1440pxで248px sidebar、71px topbar、43px本文gutterを確認する。
- 820pxで64px icon railと本文1列を確認する。
- 320px以上で本文、戻る・取消・主操作のReserved領域が画面外へ消えないことを確認する。
- skip link、メインナビゲーションのARIA、Tab順、長い日本語ページ名を確認する。

## P1-018 状態・フィードバック検査

- 保存済み、未保存、競合、接続、容量警告、処理中を文言・アイコン・色で確認する。
- 競合・エラーは最新版、差分、再試行などの次の操作を表示する。
- 進捗は`progressbar`と数値を持ち、取消・再試行をキーボードで実行できる。
- Toast、Banner、Empty、Error、Dialogの`role`、`aria-live`、focus移動、Escapeを確認する。
- 実保存、アップロード、競合API、自動マージはこの部品検査の対象外とする。
