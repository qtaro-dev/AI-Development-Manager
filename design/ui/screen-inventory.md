## 共通レイアウト

- 標準幅（1440px想定）は左ナビゲーション248px、上部バー71px、本文左右43px、本文の最大幅1640pxとする。
- 狭幅（820px想定）は左ナビゲーションを64pxのアイコンレールへ縮小し、一覧・詳細を1列へ切り替える。主要操作は常に表示する。
- 画面は「一画面一責務」とし、主操作は右上または画面下部のアクション領域へ集約する。
- WPF固有操作は、共通Web操作と同じ意味のラベルに「Windows操作」補助表示を付ける。

## 状態の扱い

| 状態 | 表示 | 利用者の次の操作 |
|---|---|---|
| 保存済み | 緑のドットと「保存済み」 | 閲覧、編集 |
| 未保存 | 琥珀色のドットと「未保存の変更」 | 保存、破棄 |
| 競合 | 赤のドットと競合バナー | 最新版・自分の変更・差分を比較 |
| 接続中 | HTTPSと緑の接続表示 | 通常操作 |
| 接続エラー | 赤い案内と追跡ID | 再試行、設定確認 |
| 容量警告 | 琥珀色の警告 | 整理候補確認、設定へ |
| 復元検証中 | 進捗と取消 | 完了待ち、取消 |
