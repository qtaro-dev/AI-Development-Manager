# P1-037 起動・接続・設定ワイヤーフレーム

P1-037は、P1-038の製品UI実装前に起動・接続・設定の状態と操作優先度をユーザー承認するための設計ゲートである。ここにあるSVGは製品画面ではなく、レイアウト、文言、状態遷移、キーボード操作を確認するための基準資料である。

## 確認対象

| 資料 | 確認する状態 | 主な判断 |
|---|---|---|
| `startup-local.svg` | 起動直後・Local開始 | Server通信なしで本体へ進めるか |
| `connection-failure.svg` | Server接続失敗 | Local継続、設定、再試行、終了へ到達できるか |
| `execution-profile-settings.svg` | 実行プロファイル設定 | Local／Serverの選択と保存の意味が明確か |
| `webview-fallback.svg` | 組み込みUI読込失敗 | 理由、再読込、設定、終了を安全に案内できるか |
| `responsive-layout.svg` | 1440／820／320px相当 | 狭幅・高DPIでも主操作が隠れないか |

## 状態遷移

```text
起動
  └─ Localを既定として開始 → 本体画面
       └─ 設定 → 実行プロファイル
             ├─ このPCで利用 → Localを保存 → 本体画面
             └─ LAN Serverへ接続 → URL検証 → 接続中
                                      ├─ 成功 → 本体画面
                                      └─ 失敗 → 接続失敗画面
                                                   ├─ このPCで続ける
                                                   ├─ 接続先を設定
                                                   ├─ もう一度試す
                                                   └─ 終了
```

組み込みWeb UIを読めない場合は、Server接続失敗とは分けてWPF fallbackを表示する。Local利用をServer障害のために失わせない。

## 文言・操作の判断材料

- 「Server」ではなく利用者向け表示は「サーバー」とする。
- `blocked`、`origin`、`fallback`、`runtime`などの専門語を画面主文に出さない。
- 初回設定画面は初回または未設定時だけ表示し、設定済みの通常起動ではLocalホームへ直接進む。
- 実行プロファイル設定ではLocal選択時のServer URLを無効化または非表示にし、LAN Server選択時だけ入力可能にする。
- 主操作は「このPCで続ける」「もう一度試す」、設定系は「接続先を設定」、終了系は「終了」とする。
- エラーの詳細は折りたたみの診断情報へ分離し、画面主文には復帰方法を置く。
- Tab順は本文の説明 → 主操作 → 設定 → 終了。Escapeはダイアログまたは設定パネルを閉じる。

## 承認ゲート

P1-038の実装開始条件は、次の項目についてユーザー承認を得ることである。

1. Local既定起動の優先度とServer非依存性
2. 接続失敗時の4操作の配置・文言
3. 設定画面でのLocal／Server選択と保存説明
4. Web UI読込失敗時のWPF fallbackの責務
5. 1440／820／320px相当と100～200% DPIでの主要操作保持

レビュー結果は本README末尾の「ユーザー承認記録」へ追記する。承認前はP1-038へ着手しない。
