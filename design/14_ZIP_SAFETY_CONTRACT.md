# ZIP安全閲覧契約

版: 0.1-p0-012
状態: PoC完了・採用候補
基準日: 2026-08-02

## 初期上限

| 項目 | 初期値 |
|---|---:|
| ZIP本体 | 500 MiB |
| エントリー数 | 10,000 |
| 個別展開サイズ | 250 MiB |
| 合計展開見積 | 2 GiB |
| 圧縮率 | 100倍 |
| ネスト深度 | 2 |
| 一時閲覧保持 | 24時間 |

上限は管理設定として変更可能な候補値であり、正式値は後続判断で確定する。

## 検査・閲覧契約

- ZIP全体を自動展開せず、ヘッダーと実読込時の上限を確認する。
- `..`、絶対パス、重複名、暗号化、壊れたZIP、過大ネスト・件数・容量・圧縮率を拒否する。
- 個別エントリーのみ期限付き一時領域へ取り出す。
- 実行形式は表示せず、ダウンロード専用とする。
- 一時領域は期限後に清掃し、永続展開キャッシュを作らない。
- 拒否理由は内部詳細と利用者向け平易な案内を分離する。

## PoC結果

`poc/zip-safety`で全検証ケース、個別閲覧、実行形式制御、期限清掃を確認した。.NET SDK 10.0.302、Runtime 10.0.10を使用した。
